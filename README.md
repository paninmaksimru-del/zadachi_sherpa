# Задачи Шерпа

Закрытая доска проекта «ИИ-агенты». Данные хранятся в `data/report.json`, приложение — в `dist/`.

Нажмите «Редактировать», внесите изменения и «Сохранить»: создаётся коммит в ветке main. Одновременные изменения защищены проверкой SHA файла. При конфликте черновик остаётся на экране: скопируйте нужные правки перед обновлением.

Для входа создайте GitHub Fine-grained personal access token: владелец paninmaksimru-del, только репозиторий zadachi_sherpa, Contents: Read and write. Токен хранится только в оперативной памяти вкладки. Read-only подходит для просмотра.

GitHub Pages недоступен для этого приватного репозитория на текущем тарифе. Приложение размещается отдельно в закрытом Sites. Приватность репозитория не меняется.

Локальный запуск: `python -m http.server 8765 --directory dist`, открыть http://localhost:8765.
