# Задачи Шерпа

Страница: https://paninmaksimru-del.github.io/zadachi_sherpa/

GitHub Pages публикует папку `docs/` из ветки `main`. `dist/` содержит ту же версию приложения для отдельного размещения.

Просмотр таблицы доступен всем без входа. Репозиторий и `data/report.json` публичны.

Для изменений нажмите «Войти для редактирования». Создайте Fine-grained token в GitHub: владелец paninmaksimru-del, только zadachi_sherpa, Repository permissions → Contents: Read and write. Токен хранится только в памяти вкладки и отправляется только в api.github.com.

«Редактировать» → правки → «Сохранить» создаёт коммит с данными в `data/report.json`. Данные загружаются напрямую из GitHub при открытии страницы. При одновременном сохранении проверяется SHA файла: чужие изменения не перезаписываются, черновик остаётся на экране. Перед обновлением скопируйте нужные правки.

Локальный запуск: `python -m http.server 8765 --directory docs`.
